# Brihaspati

**Brihaspati** is a modern, high-performance, all-in-one student productivity, learning, and AI study assistant desktop application, independently reconstructed from deep reverse engineering of NeoCoach.

## Features
- **AI Study Assistant**: Powered by Gemini and Groq with intent routing, vision/OCR support, and YouTube lecture recommendations.
- **Focus Guard**: Active window monitoring and distraction blocking to keep students focused.
- **Offline-First & Private**: Secure local data storage with zero data mixing with original apps.
- **Independent Identity**: Separate branding, app ID, and configuration paths.

## Quick Start
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run Brihaspati:
   ```bash
   npm start
   ```
